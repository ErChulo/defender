# Defender

A self-contained browser game inspired by the classic 1981 arcade shoot-'em-up.

Open `index.html` in a modern desktop browser, or serve this directory with any
static web server.

## Controls

- Left / Right: reverse or flip the ship's facing
- Up / Down: vertical thrust
- Space: fire
- B or Shift: smart bomb
- H or C: hyperspace / inviso
- P or Escape: pause
- M: mute
- F: fullscreen
- Enter: start or restart

The game uses original canvas artwork and synthesized Web Audio effects; it does
not include ROM sprites or arcade ROM audio.
